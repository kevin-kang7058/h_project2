# 오늘의 동선 · 첫 번째 버전

`index.html`을 브라우저에서 열면 실행됩니다. 설치나 빌드가 필요 없으며, 폴더 그대로 Vercel에 정적 사이트로 배포할 수 있습니다.

## 사용 방법

1. **샘플 주소 불러오기**를 눌러 출발지와 고객 주소 5개를 채웁니다.
2. 고객 주소는 한 줄에 하나씩 입력합니다. 빈 줄은 제외됩니다.
3. **경로 확인하기**를 누르면 출발지 기준 가까운 순서로 지도 번호와 목록을 표시합니다.
4. **길찾기**를 누르면 선택한 목적지와 연결 준비 안내가 나옵니다.
5. **주소 다시 입력하기**를 누르면 입력값을 유지한 상태로 돌아갑니다.

입력 화면의 **사용 가능한 샘플 주소 보기**에서 지원하는 모든 주소를 확인할 수 있습니다. 이 중 어느 주소든 출발지나 방문지로 사용할 수 있습니다. 미등록 주소는 좌표를 임의로 만들지 않고 입력 안내를 표시합니다.

## 수정할 파일

- `index.html`: 주소 입력 화면의 문구와 구성
- `route.html`: 추천 경로 화면의 문구와 구성
- `css/style.css`: 공통 색상, 크기, 화면 배치 (주요 색상은 파일 상단)
- `js/mock-data.js`: 샘플 주소와 좌표
- `js/common.js`: 주소 정리, 주소 검색, 화면 간 임시 데이터 전달
- `js/main.js`: 입력 개수, 유효성 검사, 샘플 채우기
- `js/route.js`: 거리 계산, 정렬, 목록·지도 표시, 길찾기 클릭 처리
- `assets/logo.svg`, `assets/map-preview.svg`: 간단한 SVG 이미지

## 동작 범위

- 모든 좌표와 지도는 Mock Data입니다. 실제 주소 검색이나 지도 API를 호출하지 않습니다.
- **출발 위치와 각 고객 사이의 직선거리**로 정렬합니다. 실제 도로 경로나 전체 이동거리의 최적화를 계산하지 않습니다.
- 같은 주소가 여러 줄이면 별도 방문 항목으로 유지합니다.
- 길찾기의 추후 연결 지점은 `js/route.js`의 `openNavigation()`입니다.
- 로그인·회원가입·DB 연결은 없습니다. 입력값은 현재 탭의 `sessionStorage`로만 전달합니다. 파일을 직접 연 경우 브라우저별 저장소 차이를 보완하기 위해 현재 창의 `window.name`도 사용합니다. 장기 저장 기능은 없습니다.
- 데이터 없이 `route.html`을 직접 열거나 데이터가 잘못된 경우 입력 화면으로 가는 안내를 표시합니다.
